# ❓业余无线电是什么

    业余无线电，可以理解成同钓鱼、骑行一样的爱好。

    不同的是，业余无线电需要使用无线电“业余频段”资源。无线电频谱资源宝贵且有限，一般来说，各国管理部门会将频谱资源划分给各个不同业务，如航空航天、卫星通讯、军事等用途。而部分频谱资源，被划分出来供业余无线电爱好者（又称“HAM”）使用，用于“相互通信、技术研究、自我训练”等用途。

    想成为业余无线电爱好者的一员，会有一些门槛。本文会介绍如何获取资格，行为规范，主要玩法等等。

# 🎫 获取资格

1. **操作证书 + 呼号 + 电台执照**
2. **操作证书分为A、B、C三级，通过CRAC考试即可获得证书**

|  **A类业余无线电台操作证** |  **B类业余无线电台操作证** |  **C类业余无线电台操作证** |
| --- | --- | --- |
|  | 取得A类证书`6个月后`可申请参加 | 取得B类证书及设置B类电台`2年后`可申请参加 |
1. **业余无线电台分为A、B、C三类，通过考试后向各地无委部门申请可获得批准**

| **A类业余无线电台** | **B类业余无线电台** | **C类业余无线电台** |
| --- | --- | --- |
| A类业余无线电台可以在`30一3000MHz`**范围内的各业余业务和卫星业余业务频段内发射工作，且最大发射功率**`不大于25瓦`。 | B类业余无线电台可以在各业余业务和卫星业余业务频段内发射工作，`30MHz以下`频段最大发射功率`不大于100瓦`，`30MHz以上`频段最大发射功率`不大于25瓦`。 | C类业余无线电台可以在各业余业务和卫星业余业务频段内发射工作，`30MHz以下`频段最大发射功率`不大于1000瓦`，`30MHz以上`频段最大发射功率`不大于25瓦`。 |
1. **考证流程**
- 报名A类 >> A类考试 >> 领取A类操作证书 >> 购买无线电设备 >> 申请呼号和电台执照
- 拿到A证`6个月后`报名B类 >> B类考试 >> 领取B类操作证书 >> 申请B类电台
- 拿到B证且设置B类电台`2年后`报名C类 >> C类考试

# 🧭 通联之前

    通联之前的准备工作，最好花点时间学习一些基础知识（其实考试内容已经有所涉及），如：

- 通联规范流程
- 阅读通联设备说明书
- 熟悉本地HAM常用频率及本地中继频率
- 字母解释法、Q简语、通信用英语、信号报告
- 通联日志记录及QSL卡片
- etc…
