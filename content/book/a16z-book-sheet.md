# 书单

| 标题                             | 作者                                            | 推荐语                                                                                                              |
| ------------------------------ | --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 《如何让小孩子听话：2-7岁儿童生活生存指南》        | Joanna Faber/Julie King                       | 我是 web3 中思维模型的支持者。然而，当我寻找育儿的等效思维模型时，我无从入手。这本书提供了几种框架和战术工具来解决冲突、处理情绪，我最喜欢的是如何让孩子们及时而不紧张地从一个活动转移到另一个活动的部分。         |
| 《格林奇》                          | Ray Vukcevich                                 | 那是什么，在天上——是鸟吗？是飞机吗？不，这是《格林奇》——有史以来最‘格林奇’的科幻短篇小说！                                                                 |
| 《烟树》                           | Denis Johnson                                 |                                                                                                                  |
| 《当我谈跑步时我谈些什么》                  | 村上春树                                          | 村上的这本是引人入胜的回忆录，包含了对跑步和写作及其交集和对他生活影响的反思。                                                                          |
| 《选择跑步》                         | Des Linden                                    | 我推荐这本回忆录。波士顿马拉松冠军Des Linden是一个宝藏，也是毅力的化身。                                                                        |
| 《中情局：帝国历史》                     | Hugh Wilford                                  |                                                                                                                  |
| 《忍耐：心灵、身体与人类表现的奇妙弹性极限》         | Alex Hutchinson                               | 最近我读了很多探讨毅力和耐力的书。我特别喜欢作者在耐克2小时马拉松项目期间的幕后访问和关于痛苦的章节，其中提到自行车运动员Jens Voight和Eddy Merckx。                            |
| 《你想要多拼？：掌控心理战胜肌肉》              | Matt Fitzgerald                               |                                                                                                                  |
| 《为疯子航行》                        | Peter Nichols                                 |                                                                                                                  |
| 《图论与加法组合：探索结构与随机性》             | 赵宇飞                                           | 我的朋友赵宇飞写了一本精美、充满活力的书，讲述了组合学中结构从表面随机中出现的现象，反之亦然。这本书是该领域的有趣介绍，涵盖了从Szemerédi定理到卡牌游戏SET的一切。                          |
| 《逆流而上》                         | James C. Scott                                |                                                                                                                  |
| 《枯萎：真菌与即将到来的大流行》               | Emily Monosson                                | 这是一本开放思想和发人深省的书，不仅仅是要让你对真菌大流行感到恐惧，而是让你思考进化竞争以及各种生物与有时灭绝它们的真菌之间的战略斗争。                                             |
| 《时间的孩子》                        | Adrian Tchaikovsky                            |                                                                                                                  |
| 《写作以学习》                        | William Zinsser                               |                                                                                                                  |
| 《模型思维者：你需要知道的让数据为你工作的方法》       | Scott Page                                    | 这本书教授了一系列数学模型，从网络到马尔可夫链到信号传递，并展示了它们如何应用于数据集。这听起来可能非常枯燥——事实并非如此。                                                  |
| 《经济理论的好奇文化》                    | Ran Spiegler                                  | 一本充满活力的文章集，探讨了经济理论的知识史和哲学。Spiegler 讨论了经济学家如何以及为什么以特定方式推理战略行为、（非）理性和信息等主题——同时教授概念框架并将该领域人类学化。                     |
| 《经济学一课》                        | Henry Hazlitt                                 | 充满了关于基础经济学的见解和思考。                                                                                                |
| 《AI需要你：我们如何改变AI的未来并拯救自己》       | Verity Harding                                | Harding 是一位研究人工智能与公共政策相互作用的专家，她通过过去约一个世纪的技术运动来理解现代 AI 的兴起。这本‘ AI 时代的人文宣言’论证了 AI 对社会的影响远非注定，而是由所有人来推动技术朝向其最大社会潜力。 |
| 《破碎的货币：为什么我们的金融系统在失败以及我们如何改进它》 | Lyn Alden                                     | Alden 从货币历史中提取的教训和见解，强有力地论证了去中心化数字货币如何解决货币系统过去和当前面临的挑战。                                                          |
| 《美国支付系统：支付专业人士指南》              | Carol Coye Benson/Scott Loftesness/Russ Jones |                                                                                                                  |
